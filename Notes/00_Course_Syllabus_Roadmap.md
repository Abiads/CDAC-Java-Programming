# CDAC PGCP-AI: Advanced Programming for AI (Java Programming)
## Course Syllabus & Module Roadmap

**Course Code / Standard:** PGCP-AI (ACTS Pune)  
**Total Duration:** 90 Hours  
- **Theory (T):** 36 Hours  
- **Lab (L):** 30 Hours  
- **Self-Learning (SL):** 24 Hours  
**Evaluation Scheme:**
- Theory Exam: 40%
- Lab Exam: 40%
- Internal Assessment: 20%
**Standard Version:** Java 17 (LTS)

---

## Complete Session Matrix

| Session | Focus Area | Key Concepts Covered | Lab / Practical Component |
| :--- | :--- | :--- | :--- |
| **Sessions 1 & 2** | Java Basics & Architecture | JVM Architecture, Bytecode, JDK/JRE/JVM, Data types, Scope, Wrappers, Operators, Control Statements | Basic programs (Arithmetic, Interest, Voting eligibility, Control flow) |
| **Sessions 3 & 4** | OOP & Class Design | Packages, Arrays, `String` vs `StringBuilder`, Methods, Encapsulation, Overloading, Inheritance, Abstract Classes, Interfaces, Polymorphism | Shape hierarchies, String manipulation, Bank Account OOP modeling |
| **Session 5** | Robust Error Handling | Exception Hierarchy, `try-catch-finally`, multi-catch, `throw`/`throws`, Checked vs Unchecked, Custom Exceptions | Custom validation exceptions (e.g. `InvalidAgeException`, `InsufficientFundsException`) |
| **Session 6** | Generics & Collections Overview | Autoboxing, Enums, `java.util`, `java.lang`, `java.math`, Generic classes & methods, Collection hierarchy overview | Generic Pair/Box, Basic List and Set operations |
| **Sessions 7 & 8** | Functional Programming | Functional Interfaces (`@FunctionalInterface`), Lambdas, Built-in interfaces (`Predicate`, `Consumer`, `Supplier`, `Function`) | **Lab Assignment:** Employee management data structures using `java.util` properties and lambdas |
| **Sessions 9 & 10** | Modern Stream API & Date-Time | Stream pipeline, filter, map, reduce, sort, flatMap, anyMatch, Primitive streams (`IntStream`), Java 8+ Date-Time API (`java.time`) | Employee stream queries (filtering, sorting by salary, average calculations) |
| **Sessions 11 & 12** | Concurrency & Multithreading | Thread lifecycle, `Thread` vs `Runnable`, Thread Groups, Synchronization, Race conditions & Deadlocks | Producer-Consumer, Bank transaction synchronized threads |
| **Session 13** | Java Reflection API | Dynamic class loading, inspecting constructors, fields, methods, modifiers, access control, framework use cases | Runtime inspection of classes and dynamic method invocation |
| **Session 14** | Node.js Overview & Comparison | Node.js runtime, V8 engine, Browser JS vs Node.js, REPL, Reflection in Spring/Hibernate | Node CLI basics and architecture contrast |
| **Session 15** | Spring Framework Essentials | Inversion of Control (IoC), Dependency Injection (DI), Spring Architecture, Spring MVC, Core Modules | Understanding Spring application context & architecture |
